PDF Gremza

A simple, fast and free PDF reader and editor for macOS and Windows. No ads, no accounts, no internet.

macOS

A native app, only about 1.4 MB. macOS 14 or later (Apple Silicon).

Windows

Windows 10 and 11 (64-bit). The installer adds it to Open with for PDF files.

Features

  • TabsOpen many PDFs at once. Tabs that don't fit go into the » menu
  • Page thumbnailsJump to any page with one click, or show/hide the sidebar
  • Zoom and layoutsFit width, fit page, actual size. Single page, continuous, two pages
  • SearchFind text in the whole document
  • Full Screen ModeNewOnly the page, on black. Turn pages like a presentation with the arrow keys, Space or a click
  • Acrobat shortcutsNewThe same keyboard shortcuts as Adobe Acrobat Reader, shown in the menus
  • Edit pagesNewDelete, rotate, insert blank pages or pages from other PDFs
  • Reorder pagesNewDrag thumbnails to change the order. Right-click for page actions
  • Merge and splitNewMerge several PDFs into one, or split every page into its own PDF
  • Extract pagesNewSave only the pages you want, e.g. 1-3, 5, to a new PDF
  • Export to WordNewThe text of the PDF as .docx, with paragraphs, bold, italic and font sizes
  • Export as JPGEvery page becomes an image (1.jpg, 2.jpg, …) in a new folder
  • Undo, Save, Save AsNewThe file only changes when you save. Unsaved tabs show ● and ask before closing
  • Automatic updatesNewInstalls new versions by itself, or asks you first. You choose
  • PrivateNo tracking, no accounts. The only connection is the update check, and you can turn it off

Install

macOS

Unzip it and move PDF Gremza.app to Applications. The first time: right-click the app, then Open and Open again, because the app is not notarized by Apple.

Windows

Run the installer. If Windows SmartScreen warns you, click More info then Run anyway, because the app is not code-signed.
